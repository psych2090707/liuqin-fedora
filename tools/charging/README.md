# 充电只读快照

`probe.py` 沿用旧充电调查的 GNU Build ID 读取方式，集中采集供电、Type-C、
五路热敏电阻与固件收到的充电口温度。可经已有 SSH 将源码送给 `sudo -n python3 -`，
无需安装到平板。没有认证、限流、角色写入，也不收集挑战/应答。

保存到本机私有 `out/`，采样周期建议至少 5 秒；外层 SSH 应设总超时，保留错误与缺口。
IIO 温度单位为毫摄氏度，固件读回为十分之一摄氏度；两者的读取时刻不同，不能要求逐字相等。
USB 电压×电流只是驱动遥测估计，电池净电流与双电芯建模要另行核对，不能擅自乘二。
身份必须与候选 Build ID、RAM 标记、配套模块一致；快照不能代替插拔、真实睡眠和电气验证。

当前候选、来源及人工停点见移植结果。
