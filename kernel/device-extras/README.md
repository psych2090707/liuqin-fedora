# 当前设备使用的额外内核输入

这里集中维护现机使用的额外输入。历史提取文件保留原字节；后来新增的局部修复在各自 README 说明来源和验证范围。默认 `kernel/project-patches/series` 没有因此扩展。

| 目录 | 当前用途 | 历史来源 |
|---|---|---|
| `early-wake/` | A/B 都有的早醒记录 patch 与 PM debug 配置片段 | TN0092 |
| `usb-ncm/` | A/B 都有的四补丁组合；此处 series 只列实际采用的 0001–0004 | TN0101 |
| `audio-pm/` | 只加在 B 的四补丁候选；音频 + IPCC 首次过夜观察后失响应，原因未定，不能算耗电验收通过 | TN0107、当前取证 |
| `ipcc-suspend/` | deep 睡眠期间屏蔽 IPCC 汇总中断；原音频 + IPCC 配方首次过夜失响应，现 B 另含下面的 RX 修复，新版本整夜可靠性未验收 | 早醒复盘与取证 |
| [wcd938x-irq](wcd938x-irq/README.md) | 保留 RX 共享声音 IRQ 转交，跳过 RX 不存在的 regmap 读取；RAM 音频/短睡通过，用户授权后已写 B 并完整读回/正常启动核验，整夜可靠性未验收 | 当前取证与修复 |

**没有提取**曾导致失败或已放弃的 USB 第五补丁、GENI 组合和活动音频强制 PM 增量；它们仍在历史区，不能误混入当前配方。
默认队列已有蓝牙清理修复，不再复制一份作为另一套维护入口。

完整启动配方、构建身份和测试边界看启动专题，额外输入不保证普通默认命令或 RPM 更新自动重现当前内核。
历史提取文件的来源及 SHA256 见文件来源清单；新增修复按各自 README 和任务结果追溯。原始 patch、生成器、诊断源码与失败证据仍可按上述结果找到。
