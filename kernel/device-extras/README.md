# 额外的内核输入

这里集中维护发布配方之外的诊断、USB 和音频输入。历史提取文件保留原字节；后来新增的局部修复在各自 README 说明来源和验证范围。默认 `kernel/project-patches/series` 没有因此扩展，这些输入不会自动加入默认构建。

| 目录 | 用途 | 验证状态 |
|---|---|---|
| `early-wake/` | 早醒只读记录 patch 与 PM debug 配置片段 | 已在维护设备上用于诊断；默认 idle、不记录 |
| `usb-ncm/` | 四补丁组合；此处 series 只列实际采用的 0001–0004 | 有限 USB/睡眠测试通过 |
| `audio-pm/` | 四个音频 PM clock 候选补丁 | 首次过夜观察后设备失响应，原因未定；不能算耗电验收通过 |
| `ipcc-suspend/` | deep 睡眠期间屏蔽 IPCC 汇总中断 | RAM 短睡测试通过，随后一次过夜观察失败，可靠性未验收 |
| [wcd938x-irq](wcd938x-irq/README.md) | 保留 RX 共享声音 IRQ 转交，跳过 RX 不存在的 regmap 读取 | RAM 音频/短睡通过；完整读回和正常启动已核对，整夜可靠性未验收 |

**没有提取**曾导致失败或已放弃的 USB 第五补丁、GENI 组合和活动音频强制 PM 增量。默认队列已有蓝牙清理修复，不再复制一份作为另一套维护入口。

额外输入不保证普通默认命令或 RPM 更新自动重现当前内核；构建身份和测试边界以各目录 README 及 Release 说明为准。新增修复应继续注明来源、适用基线和撤除条件。
