# Working on liuqin Fedora Remix

Read README.md, HARDWARE.md and INSTALL.md first. This is an experimental personal device port.
Consult upstream sources before changing device support. Keep hardware evidence specific to the exact artifact.
Do not flash, repartition, switch slots or erase data without explicit authorization, backups and readback checks.
Preserve SLPI disable safeguards. Never publish device calibration, serials, persist, fingerprint data or credentials.
Keep vendor firmware and locally prepared install bundles private. Do not modify read-only upstream clones.
Use scoped offline tests; do not operate the graphical desktop or change host networking automatically.
